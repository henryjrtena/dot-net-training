Routing and Tag Helpers

Lesson Objective

Learn how custom MVC routes and Tag Helpers work together to generate clean URLs for the Todo List app.

Step 1: Complete Program.cs

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();

app.MapControllerRoute(
    name: "todos",
    pattern: "todos/{filter?}",
    defaults: new { controller = "Todos", action = "Index" });

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.Run();

Step 2: Complete Controllers/TodosController.cs

using Microsoft.AspNetCore.Mvc;

namespace TodoList.Web.Controllers;

public class TodosController : Controller
{
    public IActionResult Index(string? filter)
    {
        ViewBag.Filter = filter ?? "all";
        return View();
    }

    public IActionResult Details(int id)
    {
        ViewBag.Id = id;
        return View();
    }
}

Step 3: Complete Views/Todos/Index.cshtml

@{
    ViewData["Title"] = "Todos";
}

<h1>Todos - @ViewBag.Filter</h1>

<a asp-controller="Todos"

Nice to Know Before Moving On

Common mistakes

Custom routes can silently stop matching when the pattern, action name, or route values do not line up.

How C# maps to ASP.NET Core

Routing decides which action runs, and Tag Helpers generate links that stay in sync with your route setup.

Helpful habits and style tips

Prefer Tag Helpers over hard-coded URLs so links stay correct when route patterns change later.
