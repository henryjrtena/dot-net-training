Basics of C#

C# is a typed language. Each value has a type, such as text, numbers, or true/false values.

Variables, Constants, and Data Types

string appName = "Todo Trainer";
int totalTodos = 3;
bool isLoggedIn = false;
double completionRate = 66.7;
decimal price = 19.99m;
char grade = 'A';

const string Version = "v1";

Console.WriteLine(appName);
Console.WriteLine(totalTodos);
Console.WriteLine(isLoggedIn);
Console.WriteLine(completionRate);
Console.WriteLine(price);

Control Flow

Control flow decides what your program does next. This includes if, switch, and loops.

int completedTodos = 2;
string role = "Admin";

if (completedTodos > 0)
{
    Console.WriteLine("You have completed work.");
}
else
{
    Console.WriteLine("No completed work yet.");
}

switch (role)
{
    case "Admin":
        Console.WriteLine("Full access");
        break;
    case "Member":
        Console.WriteLine("Standard access");
        break;
    default:
        Console.WriteLine("Limited access");
        break;
}

for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"For loop item {i}");
}

string[] todoTitles = { "Learn C#", "Build MVC", "Call API" };

foreach (string title in todoTitles)
{
    Console.WriteLine(title);
}

Methods, Parameters, and Return Values

A method groups logic into a reusable block. Parameters are the input. A return value is the result.

string title = "Finish tutorial";
bool isDone = false;

Console.WriteLine(GetStatusMessage(title, isDone));
Console.WriteLine(Add(4, 6));

static string GetStatusMessage(string todoTitle, bool done)
{
    return done
        ? $"{todoTitle} is completed."
        : $"{todoTitle} is still active.";
}

static int Add(int firstNumber, int secondNumber)
{
    return firstNumber + secondNumber;
}

Step by step: read the method name, check the parameters, check the return type, then call the method from your program.

Classes, Objects, and Basic OOP

A class is a blueprint. An object is a real instance created from that blueprint.

var todo = new TodoItem("Learn MVC", "Henry");
todo.MarkDone();

Console.WriteLine(todo.Title);
Console.WriteLine(todo.AssignedTo);
Console.WriteLine(todo.IsDone);

public class TodoItem
{
    public TodoItem(string title, string assignedTo)
    {
        Title = title;
        AssignedTo = assignedTo;
    }

    public string Title { get; }
    public string AssignedTo { get; }
    public bool IsDone { get; private set; }

    public void MarkDone()
    {
        IsDone = true;
    }
}

Exception Handling

Exceptions help your code respond safely when something goes wrong.

try
{
    Console.Write("Enter a number: ");
    int number = int.Parse(Console.ReadLine() ?? "0");
    Console.WriteLine(number * 2);
}
catch (FormatException)
{
    Console.WriteLine("Please enter a valid whole number.");
}
finally
{
    Console.WriteLine("Program finished.");
}

C# 8 New Features

Nullable Reference Types

This helps you be more intentional about whether a value may be null.

string requiredTitle = "Build API";
string? optionalNote = null;

if (!string.IsNullOrWhiteSpace(optionalNote))
{
    Console.WriteLine(optionalNote.ToUpper());
}

Switch Expressions

A switch expression gives you a shorter way to return a value.

bool isDone = false;
DateTime dueDate = DateTime.Today.AddDays(-1);

string status = (isDone, dueDate.Date < DateTime.Today) switch
{
    (true, _) => "Completed",
    (false, true) => "Overdue",
    _ => "Active"
};

Console.WriteLine(status);

Using Declarations

using var writer = new StreamWriter("log.txt");
writer.WriteLine("Application started");

Async Streams

await foreach (var title in GetTodoTitlesAsync())
{
    Console.WriteLine(title);
}

static async IAsyncEnumerable<string> GetTodoTitlesAsync()
{
    string[] titles = { "Learn C# 8", "Build Web App", "Call Secure API" };

    foreach (var title in titles)
    {
        await Task.Delay(100);
        yield return title;
    }
}

Indices and Ranges

string[] titles = { "Learn", "Build", "Test", "Deploy" };

string lastItem = titles[^1];
string[] firstThree = titles[..3];

Console.WriteLine(lastItem);
Console.WriteLine(string.Join(", ", firstThree));

Default Interface Methods

ITodoLogger logger = new ConsoleTodoLogger();
logger.Log("Todo saved");
logger.LogSuccess();

public interface ITodoLogger
{
    void Log(string message);

    void LogSuccess()
    {
        Log("Operation completed successfully.");
    }
}

public class ConsoleTodoLogger : ITodoLogger
{
    public void Log(string message)
    {
        Console.WriteLine(message);
    }
}

Practical Example

This sample combines collections, classes, and a switch expression into one realistic console app.

var todos = new List<TodoItem>
{
    new("Learn ASP.NET Core", "Henry", false, DateTime.Today.AddDays(1)),
    new("Build Todo API", "Ava", true, DateTime.Today),
    new("Connect React client", "Team", false, DateTime.Today.AddDays(-1))
};

foreach (var todo in todos)
{
    Console.WriteLine($"{todo.Title} | {GetStatus(todo)} | Assigned to {todo.AssignedTo}");
}

static string GetStatus(TodoItem todo) => (todo.IsDone, todo.DueDate.Date < DateTime.Today) switch
{
    (true, _) => "Completed",
    (false, true) => "Overdue",
    _ => "Active"
};

public class TodoItem
{
    public TodoItem(string title, string assignedTo, bool isDone, DateTime dueDate)
    {
        Title = title;
        AssignedTo = assignedTo;
        IsDone = isDone;
        DueDate = dueDate;
    }

    public string Title { get; }
    public string AssignedTo { get; }
    public bool IsDone { get; }
    public DateTime DueDate { get; }
}

Nice to Know Before Moving On

Common mistakes

Beginners often mix up = and ==, forget a return, or call methods on values that might be null.

How C# maps to ASP.NET Core

Classes become models, methods often become controller actions, lists become API responses, and exceptions influence app-level error handling.

Helpful habits and style tips

Use clear names, keep examples small, run often with dotnet run, and prefer readable code over clever shortcuts.
