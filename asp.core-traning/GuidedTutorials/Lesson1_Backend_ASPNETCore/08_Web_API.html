ASP.NET Core Web API

Lesson Objective

Build a clean Todo List Web API with models, controllers, status codes, and request/response JSON examples.

Step 1: Complete Models/TodoItemDto.cs

namespace TodoList.Api.Models;

public class TodoItemDto
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
    public bool IsDone { get; set; }
}

Step 2: Complete Controllers/TodosController.cs

using Microsoft.AspNetCore.Mvc;
using TodoList.Api.Models;

namespace TodoList.Api.Controllers;

[ApiController]
[Route("api/[controller]")]
public class TodosController : ControllerBase
{
    private static readonly List<TodoItemDto> Todos =
    [
        new() { Id = 1, Title = "Learn Web API", IsDone = false },
        new() { Id = 2, Title = "Connect React app", IsDone = true }
    ];

    [HttpGet]
    public ActionResult<IEnumerable<TodoItemDto>> Get()
    {
        return Ok(Todos);
    }

    [HttpGet("{id:int}")]
    public ActionResult<TodoItemDto> GetById(int id)
    {
        var todo = Todos.FirstOrDefault(x => x.Id == id);
        return todo is null ? NotFound() : Ok(todo);
    }

    [HttpPost]
    public ActionResult<TodoItemDto> Post(TodoItemDto model)
    {
        model.Id = Todos.Max(x => x.Id) + 1;
        Todos.Add(model);
        return CreatedAtAction(nameof(GetById), new { id = model.Id }, model);
    }
}

Step 3: Complete Program.cs

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();

Nice to Know Before Moving On

Common mistakes

Beginners often forget [ApiController], return the wrong status code, or change routes in a way that breaks the client.

How C# maps to ASP.NET Core

DTO classes define JSON shape, controllers expose endpoints, and status codes are part of your contract with frontend code.

Helpful habits and style tips

Make route names predictable, test endpoints early, and keep request and response models simple at first.
