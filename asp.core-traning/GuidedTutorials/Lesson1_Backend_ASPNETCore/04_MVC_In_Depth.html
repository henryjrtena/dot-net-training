ASP.NET Core MVC In Depth

Lesson Objective

Go deeper into MVC by building a Todo controller, strongly typed view models, views, form posts, and validation using complete file examples.

Step 1: Complete Models/TodoItemViewModel.cs

using System.ComponentModel.DataAnnotations;

namespace TodoList.Web.Models;

public class TodoItemViewModel
{
    public int Id { get; set; }

    [Required]
    [StringLength(100)]
    public string Title { get; set; } = string.Empty;

    [StringLength(40)]
    public string AssignedTo { get; set; } = string.Empty;
}

Step 2: Complete Controllers/TodosController.cs

using Microsoft.AspNetCore.Mvc;
using TodoList.Web.Models;

namespace TodoList.Web.Controllers;

public class TodosController : Controller
{
    [HttpGet]
    public IActionResult Index()
    {
        var todos = new List<TodoItemViewModel>
        {
            new() { Id = 1, Title = "Learn MVC", AssignedTo = "Henry" },
            new() { Id = 2, Title = "Create Todo form", AssignedTo = "Team" }
        };

        return View(todos);
    }

    [HttpGet]
    public IActionResult Create()
    {
        return View(new TodoItemViewModel());
    }

    [HttpPost]
    [ValidateAntiForgeryToken]
    public IActionResult Create(TodoItemViewModel model)
    {
        if (!ModelState.IsValid)
        {
            return View(model);
        }

        TempData["Message"] = $"Saved {model.Title}";
        return RedirectToAction(nameof(Index));
    }
}

Step 5: Complete Program.cs

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();
app.UseAuthorization();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.Run();

Nice to Know Before Moving On

Common mistakes

Forgetting model validation, posting without an anti-forgery token, or returning the wrong model type will quickly break forms.

How C# maps to ASP.NET Core

View models hold form data, controllers coordinate requests, and Razor views are strongly typed HTML templates.

Helpful habits and style tips

Keep GET and POST actions separate, validate first, and prefer small focused view models over large all-purpose ones.
